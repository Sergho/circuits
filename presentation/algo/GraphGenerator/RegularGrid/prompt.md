# Промпт

Реализуй в проекте `circuits.core` (директория `circuits.core/GraphGenerator/`)
класс `RegularGridGraphGenerator`, реализующий интерфейс `IGraphGenerator`.

Генератор строит прямоугольную решётку `rowsCount × colsCount`. Каждой клетке
сетки соответствует одна вершина. Соседи по горизонтали и по вертикали
соединены рёбрами, диагональных рёбер нет.

Параметры конструктора:

- `int rowsCount` — количество строк, > 0.
- `int colsCount` — количество столбцов, > 0.

Если параметры некорректны, выбрасывай `ArgumentException` с понятным сообщением
на русском языке.

Индекс вершины в клетке `(rowIndex, colIndex)` (с нуля) считается как
`rowIndex * colsCount + colIndex + 1` (индексы вершин в проекте начинаются с 1).

Добавляй сначала горизонтальные рёбра (по всем строкам, пары соседей по
столбцу), затем вертикальные (по всем столбцам, пары соседей по строке).

Используй соглашения по коду и доменные типы из `../context.md`.
