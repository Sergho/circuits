# Алгоритм генерации двудольного графа (Bipartite)

Генератор строит **двудольный граф** с заданными размерами двух долей и заданным
количеством рёбер. Все рёбра соединяют вершины разных долей; внутри доли рёбер нет.

## Параметры

- `leftPartitionSize` — количество вершин в левой доле (≥ 0).
- `rightPartitionSize` — количество вершин в правой доле (≥ 0).
- `edgesCount` — количество рёбер, которое нужно добавить (от 0 до
  `leftPartitionSize × rightPartitionSize`).

## Валидация параметров

1. Если `leftPartitionSize < 0` — ошибка «Размер левой доли графа не может быть
   отрицательным».
2. Если `rightPartitionSize < 0` — ошибка «Размер правой доли графа не может быть
   отрицательным».
3. Пусть `maxEdges = leftPartitionSize × rightPartitionSize`. Если
   `edgesCount < 0` или `edgesCount > maxEdges` — ошибка «Количество рёбер в графе
   должно быть между 0 и `maxEdges`».

## Шаги

1. Создать пустой граф на `leftPartitionSize + rightPartitionSize` вершинах. По
   соглашению проекта вершины с индексами `1..leftPartitionSize` — это левая доля,
   а `leftPartitionSize+1 .. leftPartitionSize+rightPartitionSize` — правая.
2. Построить список **всех возможных рёбер двудольного графа** — каждое ребро
   соединяет одну вершину левой доли с одной вершиной правой доли. Всего
   `leftPartitionSize × rightPartitionSize` рёбер.
3. Из этого списка выбрать `edgesCount` различных рёбер по схеме Фишера–Йейтса:
   - На шаге `i` (от 0 до `edgesCount - 1`):
     - Выбрать случайный индекс `k` из диапазона `[0, allEdges.Count - i)`.
     - Добавить `allEdges[k]` в результат.
     - Записать в `allEdges[k]` значение из `allEdges[allEdges.Count - 1 - i]`
       (тем самым «прячем» уже выбранный элемент в хвост, и в следующий раз он
       не попадёт под выбор).
   - В итоге получаем выборку без повторов размера `edgesCount`.
4. Добавить каждое выбранное ребро в граф (`graph.AddEdge(edge)`).
5. Вернуть граф.

## Ключевые свойства

- Граф двудольный: рёбер внутри долей не появляется.
- Все рёбра уникальны (Фишер–Йейтс гарантирует выбор без повторений).
- Количество рёбер в результате — ровно `edgesCount`.
- При `edgesCount == maxEdges` получается полный двудольный граф `K_{m,n}`.
