# Алгоритм Эрдёша–Реньи (G(n, p))

Генератор строит случайный граф **по модели Эрдёша–Реньи G(n, p)**: для каждой
возможной неориентированной пары различных вершин ребро добавляется независимо
с вероятностью `p`.

> Замечание: в коде класс называется `ErdosRenyiProbabilityGenerator`.

## Параметры

- `verticesCount` — количество вершин (≥ 0).
- `edgeProbability` — вероятность появления каждого ребра, число `p ∈ [0, 1]`.

## Валидация параметров

1. Если `verticesCount < 0` — ошибка «Количество вершин в графе не может быть
   отрицательным».
2. Если `edgeProbability < 0` или `edgeProbability > 1` — ошибка «Вероятность
   появления ребра должна быть между 0 и 1».

## Шаги

1. Создать пустой граф на `verticesCount` вершинах.
2. Завести генератор случайных чисел `Random`.
3. Перебрать все неупорядоченные пары `(i, j)`, такие что
   `1 ≤ i < j ≤ verticesCount`:
   - Сгенерировать случайное число `r ∈ [0, 1)` (например,
     `random.NextDouble()`).
   - Если `r < edgeProbability`, добавить ребро `(i, j)` в граф; иначе
     пропустить пару.
4. Вернуть граф.

## Ключевые свойства

- Ожидаемое число рёбер: `p × n × (n - 1) / 2`.
- Решения о добавлении каждого ребра независимы.
- При `p = 0` граф получается пустым, при `p = 1` — полным `K_n`.
