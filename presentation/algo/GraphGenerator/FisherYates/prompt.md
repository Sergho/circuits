# Промпт

Реализуй в проекте `circuits.core` (директория `circuits.core/GraphGenerator/`)
класс `FisherYatesGraphGenerator`, реализующий интерфейс `IGraphGenerator`.

Генератор строит случайный простой неориентированный граф с **фиксированным**
числом рёбер. Выборка рёбер выполняется по схеме частичной перетасовки
Фишера–Йейтса по списку всех возможных рёбер `(i, j)` c `1 ≤ i < j ≤ verticesCount`.

Параметры конструктора:

- `int verticesCount` — количество вершин, ≥ 0.
- `int edgesCount` — количество рёбер, от 0 до `verticesCount * (verticesCount - 1) / 2`.

Если параметры некорректны, выбрасывай `ArgumentException` с понятным сообщением
на русском языке.

Алгоритм выборки:

1. Построить список всех `maxEdges` возможных рёбер.
2. Для `i = 0 .. edgesCount - 1` выбрать случайный индекс `k` из
   `[0, allEdges.Count - i)`, добавить `allEdges[k]` в результат и записать в
   `allEdges[k]` значение `allEdges[allEdges.Count - 1 - i]`.

Для случайных чисел используй `Random`, инициализированный в конструкторе через
`new()` без seed.

Используй соглашения по коду и доменные типы из `../context.md`.
