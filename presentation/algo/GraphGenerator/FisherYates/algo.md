# Алгоритм Фишера–Йейтса для генерации случайного графа

Генератор строит случайный простой граф с заданным числом вершин и **точно
заданным числом рёбер**. Случайная выборка рёбер без повторений выполняется
по схеме частичной перетасовки Фишера–Йейтса.

## Параметры

- `verticesCount` — количество вершин (≥ 0).
- `edgesCount` — точное количество рёбер, которое окажется в графе
  (от 0 до `verticesCount × (verticesCount - 1) / 2`).

## Валидация параметров

1. Если `verticesCount < 0` — ошибка «Количество вершин в графе не может быть
   отрицательным».
2. Пусть `maxEdges = verticesCount × (verticesCount - 1) / 2`. Если
   `edgesCount < 0` или `edgesCount > maxEdges` — ошибка «Количество ребер в
   графе должно быть между 0 и `maxEdges`».

## Шаги

1. Создать пустой граф на `verticesCount` вершинах.
2. Построить список **всех возможных рёбер** простого неориентированного графа:
   пары `(i, j)` с `1 ≤ i < j ≤ verticesCount`. Размер списка — `maxEdges`.
3. Выбрать из списка ровно `edgesCount` рёбер по схеме Фишера–Йейтса:
   - Завести пустой список‑результат.
   - Для `i` от `0` до `edgesCount - 1`:
     - Сгенерировать случайный индекс `k ∈ [0, allEdges.Count - i)`.
     - Добавить `allEdges[k]` в результат.
     - Записать в `allEdges[k]` значение из `allEdges[allEdges.Count - 1 - i]`
       — это «прячет» уже выбранное ребро в хвост, и оно не будет выбрано
       повторно.
4. Добавить все выбранные рёбра в граф (`graph.AddEdge(edge)`).
5. Вернуть граф.

## Ключевые свойства

- Каждое ребро уникально; число рёбер в результате — ровно `edgesCount`.
- Любое подмножество рёбер размера `edgesCount` равновероятно (равномерная
  выборка).
- Сложность по времени — `O(n²)` на построение списка всех рёбер.

## Отличие от Эрдёша–Реньи

В G(n, p) число рёбер случайно (биномиальное распределение), а в Фишере–Йейтсе
оно фиксировано.
